# NotchLab playground prototype

A separate bright, playful design exploration. The original `website/` is untouched.

Run from this folder:

```sh
python3 -m http.server 3001 --bind 0.0.0.0
```

Open http://localhost:3001. No install or build step. Includes the existing product copy, screenshots, installation instructions, and browser-only live demo, plus three color palettes and an optional confetti interaction. Respects reduced motion. All assets are local; no dependencies or external fonts.
